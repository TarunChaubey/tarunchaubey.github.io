# Tarun Chaubey — portfolio

Static GitHub Pages portfolio for Tarun Kumar Chaubey, a **GenAI x Agentic AI Engineer** building production AI systems across RAG, agent orchestration, computer vision, cloud platforms, and MLOps.

## Run locally

No build step or server-side dependencies are required. Open `index.html` directly, or serve the repository with any static web server:

```bash
python -m http.server
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — product-style landing page, selected work, architecture explorer, experience, and contact.
- `pages/` — detailed case-study pages for GenAI/Agentic AI, machine learning, computer vision, and MLOps.
- `assets/css/style.css` — responsive visual system with dark/light themes and reduced-motion support.
- `assets/js/script.js` — theme persistence, mobile navigation, filters, architecture tabs, and scroll reveals.
- `agentic-ai.txt` — source material for the eight-layer Agentic AI architecture perspective.

The site is intentionally framework-free and uses relative paths so it remains compatible with GitHub Pages.
